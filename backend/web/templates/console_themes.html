Panduan Pengembang Tema

Sello menggunakan sistem tema berbasis file (disk-based themes). Setiap tema adalah folder di dalam direktori web/themes/.

1. Struktur Folder Tema

Setiap tema harus memiliki struktur berikut:

web/themes/[theme-slug]/
├── theme.json         # Konfigurasi utama (wajib)
├── assets/            # CSS, JS, Gambar statis
│   ├── style.css
│   └── script.js
├── layouts/           # Layout pembungkus (base)
│   └── base.html
├── pages/             # Template halaman
│   ├── home.html
│   └── product.html
├── components/        # Komponen reusable (opsional)
│   ├── navbar.html
│   └── footer.html
└── thumbnail.png      # Preview image

2. Konfigurasi (theme.json)

File ini mendefinisikan metadata, template mapping, dan opsi kustomisasi yang bisa diedit user. 

{
  "name": "Modern Store",
  "version": "1.0.0",
  "templates": {
    "home": "pages/home.html",
    "product_detail": "pages/product.html"
  },
  "settings": [
    {
      "id": "colors",
      "title": "Warna",
      "sections": [
        {
          "id": "primary_color",
          "label": "Warna Utama",
          "settings": [
            {
              "id": "main_bg",
              "type": "color",
              "label": "Background",
              "default": "#ffffff"
            }
          ]
        }
      ]
    }
  ]
}

3. Variabel Template (Go Templates)

Anda dapat mengakses data dinamis menggunakan syntax Go Template. Pastikan menggunakan format {{ .Variabel }}.

Variabel Konteks Deskripsi
{{ .Store.Name }} Semua Halaman Nama toko yang sedang dibuka.
{{ .Store.Whatsapp }} Semua Halaman Nomor WhatsApp toko (format internasional).
{{ .Store.LogoURL }} Semua Halaman URL logo toko (jika ada).
{{ .Products }} Halaman Home List (Array) semua produk aktif. Bisa diloop dengan range.
{{ .Product.Name }} Halaman Detail Nama produk yang sedang dilihat.
{{ .Product.PriceFormatted }} Halaman Detail Harga produk dalam format Rupiah (Rp 10.000).
{{ .ThemeConfig.colors... }} Semua Halaman Mengakses konfigurasi tema yang diatur user (sesuai theme.json).

4. Tema Premium & Eksklusif

Panduan untuk menandai tema sebagai konten berbayar atau khusus:

💎 Tema Premium

Tema yang hanya tersedia untuk pengguna paket berbayar (Pro/Business).

  • Saat menambah/edit tema, centang opsi Premium.
  • Tema akan otomatis terkunci untuk pengguna Free Plan.
  • Badge "PRO" akan muncul di katalog tema.

🔒 Tema Eksklusif

Tema custom yang dibuat khusus untuk satu klien tertentu.

  • Upload folder tema ke server.
  • Tambahkan ke Library tapi JANGAN centang "Aktif".
  • Hubungi developer untuk assign tema secara manual ke Store ID tertentu via database.
